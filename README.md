# Офис D-904 — ОВ и АПТ в 3D

Интерактивная 3D-аксонометрия воздуховодов (П1, В1) и пожаротушения (АПТ) офиса D-904, БЦ «STONE Towers», башня Д, 9 этаж.

- `index.html` — 3D-модель: режимы «Исходная система» и «По проекту — огибаем», узлы К1–К5.
- `images/` — картинки общего вида и узлов.

Источник: ОВ 02п-0226-ОВ л. 3, 5; АПТ 02п-0226-АПТ л. 3–5; АР разрез 1-1.
