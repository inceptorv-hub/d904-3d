# Офис D-904 — инженерные системы в 3D

Интерактивная 3D-модель офиса D-904, БЦ «STONE Towers», башня Д, 9 этаж: вентиляция П1/В1, пожаротушение (АПТ), кондиционеры VRF, освещение, АПС, СОУЭ, лючки и трассы в полу.

-  — 3D-модель: режимы «Исходная АПТ» и «Как монтируем», слои по системам, узлы К1–К6.
-  — картинки общего вида и узлов.

Источник: проекты ОВ, АПТ, ЭОМ, АПС, СОУЭ, СКС, АР.
